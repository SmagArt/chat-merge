# Merge Chat v2.8

Объединяет переписки **Telegram**, **ВКонтакте**, **Instagram** и **WhatsApp** в один файл TXT или Markdown. Расшифровывает голосовые сообщения и кружочки офлайн через OpenAI Whisper. Поддерживает GPU-ускорение (NVIDIA CUDA, Apple Silicon MPS).

---

## Логика работы (коротко)

1. **Готовишь папку** с одной перепиской (см. ниже — для каждого мессенджера свой формат экспорта).
2. **Скармливаешь её программе** — кнопка «Выбрать…» или Drag & Drop в окно.
3. Прога читает все файлы внутри: `result.json` (TG), `messages*.html` (VK/TG HTML), `*.json` (Instagram), `_chat.txt` (WhatsApp).
4. Сортирует по датам, объединяет в один поток, голосовые расшифровывает через Whisper.
5. Сохраняет `<имя контакта>.txt` или `.md` в той же папке.

Если нужна **только расшифровка аудио** (один файл или папка только с голосовыми) — кнопка «Выбрать…» → «Аудио-файл» / «Папка только с аудио», или просто перетащи аудиофайл в окно. Прога сама поймёт режим: если в папке нет файлов переписки, но есть аудио — переключится на режим транскрипции.

## Как готовить данные по каждому источнику

### Telegram — самый простой

1. Telegram Desktop → ☰ → Настройки → Продвинутые → Экспорт данных Telegram.
2. Сними галочки со всего, оставь только нужные чаты.
3. Формат: **JSON** (или HTML — оба работают). JSON предпочтительнее — точнее парсится.
4. После экспорта получишь папку вида `ChatExport_2026-04-25/chats/chat_42/` с `result.json` и медиа.
5. **Всю эту папку чата** (где лежит `result.json`) скармливаешь проге целиком, без распаковки/перетаскивания файлов.

Если экспортировал в HTML — то же самое, только внутри будут `messages.html`, `messages2.html` и т.д.

### ВКонтакте — самый муторный

VK выдаёт **один общий архив на ВСЕ переписки**. Нужно вытащить из него только нужный диалог.

**Как заказать архив:**
- vk.com/data_protection → «Запросить данные» → отметить «Личные сообщения».
- Подождать (от часа до суток).
- Скачать `Archive.zip` со страницы запроса.

**Как достать конкретный диалог:**
1. **Распаковываешь архив** (без распаковки нельзя — внутри HTML с относительными ссылками).
2. Открываешь `index.html` в корне архива (двойным кликом — откроется в браузере, кодировка не ломается, в отличие от прямого открытия отдельного `messages*.html`).
3. В меню слева → **Сообщения** → находишь нужного контакта по имени → кликаешь.
4. Смотришь в адресную строку браузера — там путь вида `messages/123456789/messages0.html`. Нужный номер — `123456789` (это ID диалога).
5. Идёшь в папке архива в `messages/` → находишь папку `123456789` → копируешь её отдельно (например, в `E:\Чаты\Аня_VK\`).
6. Эту папку (`Аня_VK`) скармливаешь проге.

**Альтернативный способ:** если ID диалога знаешь сразу — можно сразу копировать `messages/<ID>/`, не открывая `index.html`.

**Важно:** не открывай `messages0.html` напрямую двойным кликом — может сломаться отображение русских символов из-за кодировки. Достаточно того, что прога читает их корректно сама — она знает, что VK-экспорт в `windows-1251`.

**Быстрый способ через API (без ожидания архива):** `tools/vk_fetch_history.py` тянет историю
напрямую через VK API за секунды — обход долгого официального запроса.
1. Получить токен на vkhost.github.io («Kate Mobile» → «Разрешить», скопировать `access_token`
   из адресной строки). Положить в `tools/.env` строкой `VK_TOKEN=...` или передать `--token`.
2. `py tools/vk_fetch_history.py --list` — покажет все диалоги с их `peer_id` и именами.
3. `py tools/vk_fetch_history.py --peer <peer_id>` — выгрузит нужный диалог в
   `tools/vk_export/<peer_id>.json`. Эту папку скармливаешь проге так же, как HTML.

`peer_id` для лички = ID человека (виден в `--list` или в URL `vk.com/im?sel=<peer_id>`),
для бесед = `2000000000 + номер` (тоже в `--list`). Голосовые через API не приходят (как и в
HTML-экспорте). Оба способа — HTML-архив и API-JSON — поддерживаются и могут лежать в одной папке.

**Преимущество API-JSON над HTML-архивом:** через API приходят **пересланные сообщения с текстом**.
В HTML-экспорте ВК на их месте только заглушка `[N прикреплённых сообщений]` — самих тел нет.

**Способ A — кнопка «⬇ Выгрузить из ВК» прямо в программе (с v2.7).** В шапке Merge Chat:
выбираешь аккаунт (токены подхватываются из `tools/.env`) или вставляешь токен, вводишь `peer_id`,
жмёшь «Выгрузить». Программа скачивает диалог, кладёт его в `<папка>/VK_<peer>/` и сразу
подставляет как источник. Можно сохранить токен в программе («запомнить токен как…»), чтобы
в следующий раз только ввести `peer_id`.

**Способ B — `vk_fetch.bat` (двойной клик).** В корне проекта: двойной клик → вводишь `peer_id` →
json падает в `tools/vk_export/`. Несколько аккаунтов: положи в `tools/.env` `VK_TOKEN` и
`VK_TOKEN_<ИМЯ>`, второй аргумент bat = имя аккаунта (`vk_fetch.bat <peer_id> <имя>`).

> **Грабли:** один `peer_id` у разных аккаунтов пишется в один файл `vk_export/<peer>.json` и
> *дописывается* → диалоги двух аккаунтов смешаются. Кнопка в GUI (способ A) чистит файл перед
> выгрузкой автоматически; при ручном запуске удали старый `<peer>.json` сам.

### Instagram

1. instagram.com → Настройки → Центр аккаунтов → Ваша информация и разрешения → Скачать информацию.
2. Выбрать «Сообщения» → формат **JSON** → диапазон дат.
3. Дождаться письма, скачать архив, **распаковать**.
4. Внутри будет `your_instagram_activity/messages/inbox/<имя_контакта>_<хэш>/` — это и есть папка одного диалога с файлами `message_1.json`, `message_2.json` и т.д. Её скармливаешь проге.

### WhatsApp

1. На телефоне открой нужный чат → ⋮ → Ещё → Экспорт чата.
2. Выбери «**Включить медиафайлы**» (если хочешь расшифровку голосовых) или «Без медиа» (только текст).
3. Получишь ZIP-архив (на iOS — через «Поделиться» → «Сохранить в Файлы»; на Android — обычно через мессенджер себе).
4. **Распакуй архив**. Внутри: `_chat.txt` + медиа (`.opus`, `.jpg`, `.mp4` и т.д.).
5. Эту распакованную папку скармливаешь проге.

### Несколько источников одного контакта

Создай папку с именем контакта. Внутри — подпапки с экспортами из разных мессенджеров:
```
<контакт>/
├─ tg/                  ← папка из Telegram-экспорта (с result.json)
├─ vk/<id_диалога>/     ← папка с VK messages*.html
├─ wa/                  ← распакованный WhatsApp
└─ ig/<имя_контакта>/   ← папка из Instagram
```
Скармливаешь корневую — прога сама обойдёт все подпапки и склеит всё в одну ленту по датам.

В таких папках обычно у одного человека **разные ники** в TG/VK/IG/WA. Чтобы в выводе не было каши, в настройках включи галку «Дополнительно: разные имена для вывода» и заполни поле «Собеседник →» — все имена собеседника сольются в одно.

## Возможности v2.8

### Новое в v2.8

- **Кнопки управления моделями Whisper** — под выбором модели появились «⬇ Скачать модель» и «🗑 Удалить модель». Все действия отражаются на диске: скачивание кладёт `.pt` в папку программы, удаление физически стирает файл. Раньше модель тянулась неявно при первом запуске расшифровки — без прогресса и без возможности управлять.
- **Многопоточная загрузка моделей (в 8 соединений)** — модель качается параллельными потоками, как менеджер загрузок. На медленном/шейпленном канале это в 2–3 раза быстрее одного потока. С докачкой: обрыв не теряет прогресс, продолжает с места.
- **Проверка целостности (SHA256)** — после загрузки модель сверяется по контрольной сумме. Битый или недокачанный файл больше не выдаёт себя за рабочий. Честный статус: «готова» / «скачана не полностью» / «не скачана».
- **Обновление Whisper кнопкой** — в окне «О программе» у установленного Whisper теперь три кнопки: Установить / Обновить / Удалить.

### Из версии 2.7

- **Кнопка «⬇ Выгрузить из ВК» в шапке** — выгрузка диалога ВК через API прямо из программы, без терминала. Выбор аккаунта (токены из `tools/.env` или сохранённые в программе), поле `peer_id`, лог скачивания. Результат сразу подставляется как источник. См. раздел «ВКонтакте».
- **`vk_fetch.bat`** — выгрузка ВК двойным кликом для тех, кто не открывает программу.
- **Окно всегда влезает по высоте, лог виден** — окно подгоняется под реальную высоту содержимого (без пустоты снизу), а если экран низкий — ужимается только лог-бокс, но не меньше 140px. Кнопка «Запустить» больше не уезжает под край.
- **Поддержка VK API-JSON в установленной программе** (была добавлена в коде, но не входила в апрельский установщик) — пересланные сообщения разворачиваются с текстом.

### Из версии 2.5

- **Изменяемый размер окна** — окно тянется, минимум 900×720, контент-блок «Процесс» с логом растягивается под доступную высоту. На 1920×1080 умещается полностью.
- **Один стиль модальных окон** — диалоги (выбор источника, установка/удаление Whisper, О программе, Справка) — оверлеи поверх главного окна.
- **Кнопка «Справка»** в шапке — все подсказки в одном месте.
- **Подсказки** возле каждой настройки — наведи курсор на «?», всплывает короткое пояснение. Подробности — в этом README.
- **Поле «Твоё имя»** — одно (используется и для распознавания, и как подпись в выводе). Если хочешь подписать себя в выводе иначе — включи галку «Дополнительно: разные имена для вывода».
- **Авто-определение «себя» в Instagram и WhatsApp** — раньше для IG/WA было обязательно вручную совпасть с никнеймом, иначе твои сообщения подписывались именем собеседника. Теперь твоё имя берётся из метаданных экспорта.
- **Пресеты** — три быстрые кнопки: Диалог, Группа, Канал.
- **Полная изоляция Whisper** — и пакеты (Whisper, PyTorch), и скачанные модели лежат внутри папки проги (`local_packages\`, `whisper_models\`), а не в системном Python и не в общем кэше `~/.cache`. Удаление проги вычищает из системы всё, что она ставила. С другими программами не конфликтует.
- **Статус моделей Whisper** — под выбором модели (tiny…large) видно, какая модель уже скачана (зелёная рамка), а какая нет и сколько весит. С v2.8 статус проверяет целостность файла, а скачивание/удаление вынесено на кнопки.
- **Релиз памяти** — после обработки модель Whisper выгружается, RAM освобождается (~3–4 ГБ).
- **Двухэтапная отмена** — первый клик «Отмена» дожимает текущий файл и пропускает остальные. Второй клик — мгновенный выход.
- **Прогресс расшифровки в режиме «только аудио»** — устройство (CPU/GPU), модель, прогресс по файлам.
- **Жёсткий выход при закрытии окна** — сразу убивает Python-процесс. Раньше python.exe иногда висел в фоне с моделью в памяти.
- **Whisper под `pythonw.exe`** — исправлен баг с `tqdm`, из-за которого расшифровка возвращала пустой текст.
- **Копирование лога** — кнопка «Скопировать лог» кладёт текст в системный буфер обмена; вставка работает и после закрытия программы.

### Базовое (из прошлых версий)

- Парсинг Telegram (JSON и HTML), ВКонтакте (HTML), Instagram (JSON), WhatsApp (TXT).
- Объединение нескольких папок одного контакта.
- Расшифровка голосовых и видео-кружочков через Whisper (офлайн).
- GPU-ускорение: NVIDIA CUDA, Apple Silicon MPS.
- Фильтр по датам (range-picker).
- Фильтр по автору и тексту (regex).
- Метки источников `[TG]`/`[VK]`/`[IG]`/`[WA]`.
- Счётчик источников в шапке файла: `Сообщений: 792 (TG: 410, VK: 280, WA: 102)`.
- Форматы вывода: TXT и Markdown.
- Метки времени: вкл/выкл.
- Разбивка на файлы: один / по месяцам / по годам.
- Кэш расшифровок — повторный запуск мгновенный.
- Drag & Drop папок и файлов прямо в окно.
- История 5 последних папок.
- Авто-открытие итогового файла после готово.

## Установка

### Windows

**Вариант 1 — установщик (рекомендуется, Python не нужен):**
1. Скачай `MergeChat_Setup_v2.8.exe` из [Releases](https://github.com/SmagArt/chat-merge/releases).
2. Запусти, следуй инструкциям. Python и базовые пакеты ставятся в `%LocalAppData%\Programs\MergeChat\python\`.
3. При первом запуске жёлтый банннер «Whisper не установлен» — нажми «Установить». Прога сама определит, есть ли NVIDIA, и поставит CUDA-версию PyTorch (или CPU).

**Вариант 2 — если Python уже установлен (3.10–3.13):**
1. Скачай исходники.
2. Запусти `setup_base.bat` — поставит зависимости.
3. Запусти `setup_whisper.bat` — поставит Whisper и PyTorch (CUDA, если есть NVIDIA).

### macOS

**Вариант 1 — готовый DMG:**
1. Скачай `MergeChat_v2.8.dmg` из Releases.
2. Открой DMG, перетащи MergeChat в Программы.
3. При первом запуске: правый клик → Открыть (обход Gatekeeper).

**Вариант 2 — сборка из исходников:**
```bash
git clone https://github.com/SmagArt/chat-merge.git
cd chat-merge
bash build_mac.command
```

## Использование

1. Запусти Merge Chat.
2. **Укажи источник**: «Выбрать…» или Drag & Drop папки/файла.
3. *(Опционально)* жми «Диалог» / «Группа» / «Канал» — пресет накатит типичные настройки.
4. Введи **своё имя** так, как оно записано в мессенджерах (можно через запятую несколько вариантов).
5. *(Для 1-на-1 переписок из нескольких мессенджеров)* поставь галку «Дополнительно: разные имена для вывода» и заполни «Собеседник →» — все имена контакта из TG/VK/IG/WA сольются в одно.
6. Выбери **модель Whisper** (для русского рекомендуется `medium`).
7. *(Опционально)* — фильтр по датам, фильтр по автору/тексту, разбивка на файлы по месяцам/годам, метки источников.
8. Нажми **«Запустить»**.

После завершения — «Открыть папку» (зелёная — итоговый файл подсветится в проводнике).

### Подсказки в UI

- В шапке кнопка **«Справка»** — открывает оверлей с быстрым стартом и основными разделами.
- Возле каждой настройки — кружок «?». Наведи курсор — всплывёт короткое пояснение. Все подробности — в этом README.

### Скорость расшифровки голосовых

| Железо | Модель `medium` |
|---|---|
| NVIDIA RTX 3060 Ti | ~241 голосовое за ~8 минут |
| Apple M1/M2 (MPS) | ~5–7 минут / 100 голосовых |
| CPU (Ryzen 5/Intel i5) | в 5–10 раз медленнее GPU |

Кэш расшифровок (`.transcribe_cache`) сохраняется рядом с папкой — повторный запуск пропустит уже расшифрованные файлы.

```
  НОЯБРЬ 2024
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

С включённой кнопкой `🏷 [TG]` (или пресетом «Группа»):


С включённой галкой «Дополнительно» и заполненным «Собеседник → <имя>» — все варианты имени собеседника сольются в одно во всех источниках.

## Системные требования

- Windows 10/11 или macOS 11+.
- 4 ГБ RAM (8 ГБ для модели `large`).
- Для GPU: NVIDIA с CUDA 12.4+ или Apple Silicon (M1+).
- Интернет — только при первой установке пакетов и скачивании модели Whisper.

## Частые проблемы

**«Whisper не вернул текст» / пустой результат на аудио:**
- В v2.5 главная причина исправлена (`tqdm` под `pythonw.exe`). Если всё ещё пустой — проверь:
  - В логе после запуска есть строка `ffmpeg: <путь>` — Whisper не работает без ffmpeg. Если `НЕ НАЙДЕН` — переустанови Whisper из UI (он подтянет `imageio-ffmpeg`).
  - Файл реально содержит звук (открой в плеере).
  - Очень короткие/тихие записи Whisper иногда отдаёт пустыми — это нормально.

**Расшифровка идёт на CPU, хотя есть NVIDIA:**
- В логе после запуска должна быть строка `Устройство расшифровки: NVIDIA GeForce …`. Если стоит `CPU` — открой «О программе» → «Удалить Whisper» → потом «Установить» заново. Прога сама определит NVIDIA и поставит CUDA-вариант.
- Если не помогло — проверь `nvidia-smi` в командной строке. Если её нет — обнови драйвер NVIDIA.

**ВК-сообщения с битыми символами:**
- Открывай `index.html` (а не `messages0.html` напрямую) — у общего индекса корректная кодировка-метаинформация.
- Проге это не нужно — она читает `windows-1251` сама.

**Прога говорит «уже запущена», хотя я её закрыл:**
- В v2.5 закрытие окна сразу убивает процесс. Если ты на v2.4 — обнови. Если всё-таки висит — открой Диспетчер задач, найди `python.exe` или `pythonw.exe` и закрой.

**В выводе у одного человека разные имена в разных мессенджерах:**
- Поставь галку «Дополнительно: разные имена для вывода» и заполни поле «Собеседник →» — все имена сольются в одно.
